# Airy Aurora

A frosted pastel look in ice blue and blush, kept consistent across the desktop and the apps around it. Every part has a light and a dark mode that share one palette.

| Part | What | Where |
|---|---|---|
| **Hyprland** | The full desktop rice for KooL Hyprland: waybar, kitty, hyprlock, swaync, rofi, with a one-key light/dark switch | [airy-aurora-hyprland](https://github.com/ProtonCats/airy-aurora-hyprland) |
| **Spotify** | A Spicetify theme for the desktop client | [`spotify/`](spotify/) |
| **Discord** | A personal Vencord theme with the same palette. Not published: its background image isn't mine to redistribute | |
